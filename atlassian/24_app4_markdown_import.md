## 1. Продукт одной строкой

**Загрузить папку или zip с .md и картинками → дерево обычных страниц Confluence: содержимое
ищется и правится, картинки — вложения страниц, ссылки между файлами — ссылки между страницами;
повторная загрузка обновляет те же страницы, а не плодит копии. Всё в браузере и в Forge,
без OAuth к GitHub и без сервера вендора. Runs on Atlassian.**

Обратная половина ArtUp Export: Confluence → Markdown → Confluence без потерь.

Рабочее название: **ArtUp Import** (ключ `com.artuplabs.import`, коммиты `IMPORT-<n>`).

## 5. Границы v1

### Входит

1. **Точки входа:** кнопка в меню пространства / дерева страниц и своя страница приложения
   (`confluence:spacePage` или `confluence:globalPage` — выбрать по I-G5), импорт под выбранную
   родительскую страницу.
2. **Вход:** папка (`webkitdirectory`) или .zip; .md и .markdown; картинки png/jpg/gif/svg/webp;
   front matter (`title`, `slug`) — заголовок страницы; `index.md` / `README.md` / `_index.md` — страница папки.
3. **Разметка:** CommonMark + GFM (таблицы, чек-листы, зачёркивание, автоссылки), блоки кода
   с языком → макрос code, `> [!NOTE]` и admonitions MkDocs/Docusaurus → панели, сноски, HTML-теги —
   безопасное подмножество.
4. **Повторный импорт:** сопоставление по пути файла (свойство страницы), обновление только
   изменённых, отчёт «создано / обновлено / без изменений / ошибки», пробный прогон без записи.
5. Лицензия ≤ 10 пользователей бесплатно; 26 языков; светлая/тёмная тема — как в Trace/Export/Reports.

### Не входит в v1

- Синхронизация прямо из GitHub/GitLab — нужен egress или OAuth (v1.1 — проверить отдельно).
- Удаление страниц, файла которых больше нет (v1 — только отчёт о таких страницах).
- Макрос показа .md без импорта (рынок Just Add+ / Render Markdown) — отдельное решение после листинга.
- Confluence Data Center; Obsidian-ссылки `[[...]]` — v1.1.

## 6. Архитектура (гипотеза до I-G5)

- Custom UI читает файлы в браузере (File API / распаковка zip библиотекой в бандле),
  разбор Markdown (`micromark`/`mdast`) → модель → storage format или ADF — **чистые функции без I/O**.
- Запись — `requestConfluence` от имени пользователя: создание и обновление страниц
  (`/wiki/api/v2/pages`), вложения (`/wiki/rest/api/content/{id}/child/attachment`), свойства
  страниц для связи файл ↔ страница. Конкурентность и повтор 429 — конвейер ArtUp Export.
- Резолвер — только лицензия и настройки; лимиты Forge (25 с, 5 МБ) сборки не касаются.
