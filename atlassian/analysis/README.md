# Разборы отчётов

Проверка отчётов из [../](../) на прочность: пересчёт арифметики из их же
цифр, сверка утверждений между документами и измерение того, что в отчёте
принято на веру. Разбор не заменяет отчёт и не переписывает его вывод — он
говорит, какие числа выдержали проверку, а какие нет.

Правило: то, что автор отчёта раскрыл сам в разделе «Чего в этом отчёте
нет», находкой не считается.

- [category_price_fit_review.md](category_price_fit_review.md) —
  какая из семи категорий-кандидатов отчёта [../04_market_measurement.md](../04_market_measurement.md)
  держит цену, нужную для цели за ~12 месяцев.

  ступенях 50/200/1000 мест, клиентов до $5 000, установок под них и в какие
  верхние % листингов категории это ставит
