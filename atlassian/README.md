десяти кандидатов в [../ideas/01_third_sphere_market_analysis.md](../ideas/01_third_sphere_market_analysis.md).

своих продаж и без звонков.**

## Разборы

- [analysis/](analysis/) — проверка отчётов на прочность: пересчёт их
  арифметики, сверка утверждений между документами, измерение принятого на
  веру. Сделан разбор ценовой пригодности семи категорий-кандидатов из 04.
- [06_niche_selection.md](06_niche_selection.md) —
  выбор ниши. Метод гейта из плана 05 заменён: отбор по отзывам меряет размер
  приложения, а не спрос. По дефициту предложения выбран **экспорт**
  (101 приложение, топ-3 держат 27%, $147/мес на 200 мест, 34 клиента до цели).
  Главный аргумент доки 02 снят: **Forge-нативность — входной билет, а не
  преимущество**, 60–88% лидеров уже на Forge. В приложении — как замер сам
  себя чуть не обманул на HTTP 410.
- [07_export_listings.md](07_export_listings.md) —
  сырьё для следующего шага: все 101 листинг темы «экспорт» с установками,
  ценой на 200 мест, признаком Forge и слоганом. Читать руками, чтобы
  получить «экспорт чего во что»; закрытие темы — нормальный исход.
- [08_ceiling_and_growth.md](08_ceiling_and_growth.md) —
  $5 000/мес это цель папки, а не потолок площадки: Appfire делает $200 млн
  ARR там же, средний партнёр ~$1 млн/год. Цель достигается ниже p90
  распределения. Рычаги роста по силе, портфельный эффект измерен
  (1 приложение — медиана 43 установки, 10+ — 4 827). Поправка: ревшара 100%
  держится **16.7 лет** при $5 000/мес — порог $1 млн накопительный.
- [09_timeline_measured.md](09_timeline_measured.md) —
  срок измерен по 220 листингам: медианный новый листинг **не берёт порог
  и за три года**; 12–20 месяцев — исход верхних 15–25%. Рычаги ускорения
  по силе: состав клиентов (**в 12 раз**), внешний трафик, и только потом
  скорость разработки.
- [10_action_list.md](10_action_list.md) —
  **что делать руками**: шесть действий, около двух часов и $15–60.
  Первое решает срок, остальные пять просто обязательны.
- [11_feature_requests.md](11_feature_requests.md) —
  **лучший найденный метод**: публичный трекер Atlassian отдаёт 9 922 открытых
  предложения с голосами — это непокрытая потребность, а не занятость рынка.
  Ретро проверено и отклонено (38 приложений, медиана 38 установок, в трекере
  спроса нет). Markdown подтверждён: 2 900 голосов, 5–7 лет без решения — но
  платят за **docs-as-code** ($175–450), а «Markdown для LLM» занят
  бесплатными приложениями Anthropic, Cursor и GitHub. Плюс топ-5 запросов.
- [12_markdown_export_niche.md](12_markdown_export_niche.md) —
  разбор ниши и лидера. **Лучше — да**, четыре дефекта Markdown Exporter
  известны поимённо из его отзывов (не экспортирует внуков, теряет порядок
  страниц, ломает диакритику, медленный). **Дешевле — нет**: лидер уже
  вдвое дешевле рынка, а цена ниже переводит в сегмент, где цель берут 2%
  вместо 24%. Предложение: $150–175, отличие — стабильные пути,
  front-matter и инкрементальность, то есть экспорт, пригодный для git.
- [13_demand_report.md](13_demand_report.md) —
  **отчёт по спросу и топ-5**: 300 верхних открытых предложений Atlassian
  (157 823 голоса) сопоставлены с каталогом. Главный вывод: высокие голоса
  при нулевом предложении обычно означают **невыполнимость**, а не нишу —
  три верхних запроса упираются в ограничения платформы. Топ-5 отобран по
  голосам × тонкое предложение × выполнимость без egress.

- [14_domain_scan.md](14_domain_scan.md) —
  **замер предметной области под вариант В.** Розницы в каталоге **нет
  вообще**: 0 листингов из 6 268 по POS, остаткам, каннабису, пищевой
  безопасности — Jira покупает команда умственного труда, а магазин живёт в
  POS и ERP. Зато найден ценовой рычаг: чем жёстче регулятор, тем меньше
  листингов и тем больше установок у каждого («фарма и GxP» — 4 листинга,
  медиана 417 установок). Цены сняты по 92 листингам, 0 отказов: медиана
  $142 на 200 мест, но у листингов с установками **$383–914, то есть
  5–13 клиентов до цели вместо 34**. Рабочий образец — SoftComply:
  11 листингов, 2 390 установок, вся ставка на одну регулируемую область.
  В конце — развилка В1/В2/В3, нужен выбор.

## Инструменты

Замер площадки, всё без авторизации и бесплатно. Запускать из этой папки —
пути по умолчанию (`data/apps.json`) отсчитываются от неё:

- [tools/fetch_marketplace.py](tools/fetch_marketplace.py) — выгрузка всех облачных листингов
- [tools/analyze_marketplace.py](tools/analyze_marketplace.py) — категории: спрос против свежести предложения
- [tools/fetch_pricing.py](tools/fetch_pricing.py) — реальные цены по ступеням пользователей
- [tools/fetch_reviews.py](tools/fetch_reviews.py) — отрицательные отзывы у лидеров категории
- [tools/analyze_reviews.py](tools/analyze_reviews.py) — сводка тем в отрицательных отзывах
- [tools/check_forge_native.py](tools/check_forge_native.py) — кто из лидеров уже на Forge
- [tools/fetch_suggestions.py](tools/fetch_suggestions.py) — фичареквесты Atlassian по голосам
- [tools/measure_ramp.py](tools/measure_ramp.py) — скорость набора установок по возрасту листинга
- [tools/check_manifest_permissions.py](tools/check_manifest_permissions.py) — гейт мажорных версий Forge для CI
- [analysis/scan_domain.py](analysis/scan_domain.py) — плотность предложения по предметной области
- [analysis/price_domain.py](analysis/price_domain.py) — реальные цены по ступеням для тем скана

Замечание по API: поштучные ресурсы `/addons/{key}/...` отдают **410 Gone**
на не-браузерный User-Agent. Списочные, цены и отзывы работают с любым.
Инструменты это учитывают и **не выдают отказ за отсутствие данных** — см.
[06](06_niche_selection.md), приложение.
