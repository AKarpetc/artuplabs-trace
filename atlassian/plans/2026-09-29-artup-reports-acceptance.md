### Матрица шаблонов: находки

- **Исправлено (`REPORTS-23`, отдельный коммит с тестами):** в PDF таблицы и «коробки» (блок кода, панель)
  строились с колонками `*`; pdfmake растягивает такую колонку до самого длинного неразрывного слова,
  поэтому URL или длинный идентификатор в ячейке, коде или панели выталкивали таблицу за правое поле и
  за край страницы. Теперь колонкам выдаётся точная ширина, которую оставляет страница; вложенные
  изображения и панели считаются от неё.
- **Не исправлено, записано:** в списочных макетах (PDF и Word «список задач», «отчёт по спринту»)
  колонки одной ширины — «Summary» такая же узкая, как «Key» и «Type», строки с длинным заголовком
  получаются очень высокими. Ничего не обрезается. Улучшение — веса колонок в модели макета (общая
  правка `core/layouts.js` для Word и PDF), в v1.1.
- **Проверить в Word (C2):** в Word-файле блок кода с иероглифами в LibreOffice рисует квадраты вместо
  CJK-знаков (шрифт Consolas, у LibreOffice нет подстановки); в Word подстановка обычно есть, но это
  не проверено. Основной текст, заголовки и таблицы с CJK выглядят верно.
- Матрица целиком: `apps/reports/data/matrix/index.html` (не в git, воспроизводится
  `node scripts/template-matrix.mjs`); файлы `.pdf`, `.docx` и растры лежат рядом.

### Как повторить

```
set -a && . /Users/artyomkarpets/IncomeApps/projects/DistributB2B/.env && set +a
cd apps/reports
node scripts/acceptance.mjs xlsx --jql "project = RPT" --template xlsx-issues --min-rows 10000 --out data/rpt-10k.xlsx
node scripts/acceptance.mjs docx --jql "project = RPT AND attachments is not EMPTY" --limit 500 --template docx-single --out data/rpt-500.docx
node scripts/acceptance.mjs pdf  --jql "project = RPT AND attachments is not EMPTY" --limit 500 --template pdf-single  --out data/rpt-500.pdf
node scripts/acceptance.mjs docx-template --jql "project = RPT AND key <= RPT-100" --limit 100 --template-file data/example.docx --out data/rpt-template.docx
node scripts/acceptance.mjs xlsx --jql "project = RPT" --template xlsx-worklogs --out data/rpt-xlsx-worklogs.xlsx
node scripts/acceptance.mjs xlsx --jql "project = RPT" --template xlsx-comments --out data/rpt-xlsx-comments.xlsx
node scripts/acceptance.mjs docx --jql "project = RPT AND attachments is not EMPTY" --multiply 4 --limit 2000 --template docx-single
node scripts/acceptance.mjs pdf  --jql "project = RPT AND attachments is not EMPTY" --multiply 4 --limit 2000 --template pdf-single
node scripts/synthetic.mjs --issues 50000
node scripts/template-matrix.mjs
```

`data/example.docx` — копия `static/app/public/example-template.docx`. Скрипт `acceptance.mjs` печатает
`pass` и причины провала и завершается кодом 1, если порог не выдержан; для прогонов `--multiply` он
показывает «took … limit 120 s» — порог 120 с относится к 500 задачам, на 2 000 он не применяется.
