# Фичареквесты как источник спроса: ретро и Markdown

Дата: 2026-09-15. Проверка двух идей методом, который меряет **непокрытую
потребность**, а не занятость рынка.

## Метод, и почему он лучше всех предыдущих

Публичный трекер Atlassian `jira.atlassian.com` отвечает по REST **без
авторизации**: **5 596** открытых предложений в Jira Cloud и **4 326** в
Confluence Cloud, с числом голосов и подписчиков.

Это принципиально другой сигнал. Ключевые слова в листингах и отзывы у
лидеров показывают, **что занято**. Голоса за нерешённое предложение
показывают, **чего людям не хватает** — и сколько их. Открытое предложение
с тысячей голосов, висящее семь лет, — это задача, которую Atlassian не
сделала и делать не собирается.

Инструмент: [tools/fetch_suggestions.py](tools/fetch_suggestions.py).

**Проверка метода на известном исходе.** `CONFCLOUD-1732 «Numbered Headings»` —
671 голос, открыт с **2004 года**. На Marketplace приложение «Numbered
Headings» имеет **5 280 установок** по $121/мес. Голоса за нерешённое
предложение конвертируются в установки приложения. Метод рабочий.

## 1. Ретро — плохая ставка, и это видно с трёх сторон

### Marketplace

38 приложений, суммарно **8 156 установок**, медиана **38**, топ-3 держат **64%**.

| Установок | Приложение |
|---|---|
| 3 370 | Easy Agile TeamRhythm: Story Map, Insights & Retro |
| 988 | SprintRetro (бесплатное) |
| 871 | Agile Retrospectives for Jira |
| 775 | Agile Planning Poker, Retrospectives, Daily Standup |

Для сравнения: тема «экспорт» — 67 приложений с медианой **456** установок.
Ретро в двенадцать раз реже ставят.

### Трекер Atlassian

Открытых предложений со словом retrospective — **10 на оба продукта**, и ни
одно из них на самом деле не про ретро (совпадения по другим словам). Люди
не просят ретро в Jira.

### Опенсорс

| Звёзд | Репозиторий |
|---|---|
| 346 | inovex/scrumlr.io |
| 54 | vijeeshr/quickretro |
| 21 | haggen/hindsight |
| ≤19 | всё остальное |

Ни одного крупного проекта. Для сравнения, живые категории опенсорса дают
тысячи звёзд.

### Почему так

Ретро проводят **не в Jira**, а в Miro, EasyRetro, Parabol, TeamRetro — там,
где вся команда и свободный холст. А связку «карточка → экшен-айтем», ради
которой идея и возникла, **уже закрыл лидер**: Easy Agile TeamRhythm (3 370
установок) делает ровно это — ретро с созданием задач Jira из карточек.

**Вывод: не брать.** Маленький рынок, нет спроса в трекере, ключевая функция
занята лидером, и общая выручка всей категории меньше, чем у одного среднего
приложения из темы «экспорт».

## 2. Markdown — сильный сигнал, но не там, где кажется

### Спрос в трекере

Открытых предложений со словом markdown — **70**. Верх:

| Голосов | Следят | Открыто с | Предложение |
|---|---|---|---|
| **1 757** | 509 | **2019** | Provide users with a plain text markdown editor (JRACLOUD-72631) |
| 533 | 258 | 2019 | Edit in Markdown with the new editor (CONFCLOUD-68272) |
| **379** | 204 | **2021** | Public REST API для конвертации между ADF, HTML и Markdown (JRACLOUD-77436) |
| 240 | 135 | 2019 | Full markdown support for the new editor (CONFCLOUD-68137) |

Почти **2 900 голосов** на четырёх открытых предложениях, ни одно не закрыто
за 5–7 лет. По голосам markdown-редактор входит в **топ-8 всех** запросов к
Jira Cloud из 5 596.

Третья строка — техническая суть: Confluence и Jira хранят содержимое в
формате ADF, и публичного способа конвертировать его в Markdown нет. Это и
есть барьер, из-за которого задача не решена.

### Предложение на рынке

| Тема | Приложений | Суммарно установок |
|---|---|---|
| Markdown | 63 | **32 590** |
| Git-синхронизация | 29 | 12 078 |
| AI / LLM-контекст | 96 | 17 757 |

### И здесь главная развилка

**Обёртка «Markdown для LLM» — ловушка.** Верх этой темы занят
**бесплатными приложениями самих вендоров**:

| Установок | Приложение | Цена |
|---|---|---|
| 6 710 | Claude Agent for Jira | **бесплатно** |
| 3 023 | Cursor | **бесплатно** |
| 2 868 | GitHub Copilot for Jira | **бесплатно** |

Anthropic, Cursor и GitHub раздают свои интеграции даром, чтобы продавать
подписку на модель. Конкурировать с бесплатным продуктом, за которым стоит
компания с другой моделью дохода, — заведомо проигрышно.

**А вот docs-as-code — платят, и по корпоративной цене:**

| Установок | $/мес 200 | Приложение |
|---|---|---|
| 1 078 | **$175** | Git for Confluence (GitHub, GitLab, Bitbucket) |
| 1 033 | — | Include from Bitbucket to Confluence (Markdown) |
| 275 | **$450** | GitLab Integration for Jira Two-Way Sync (Forge) |
| 235 | $64 | Include from GitHub to Confluence (Markdown) |

$175 и $450 за 200 мест — это верхний квартиль рынка ([04](04_market_measurement.md) §3:
медиана $147, p75 $189). **Корпоративный сегмент — тот самый рычаг в 12 раз
из [09](09_timeline_measured.md) §4.1.**

Ваша формулировка — «загружать md, подключать к git, выгружать md с
проектов» — это и есть docs-as-code. Правильная рамка не «Markdown для
LLM», а **«документация живёт в git, отображается и редактируется в
Confluence»**. Первая конкурирует с бесплатным, вторая продаётся по $175–450.

### Как читать эту таблицу

Голоса — не гарантия. Они означают, что задача существует и не решена
платформой; они **не** означают, что за решение заплатят и что его не
закрыло приложение с другим названием. Каждую строку надо проверять так же,
как проверялась связка «экспорт + согласование» в [10](10_action_list.md) §1 —
и она там не прошла.

Порядок проверки строки, полчаса на строку:

1. Найти приложения, закрывающие задачу (поиск по каталогу, не по ключевому
   слову в названии — урок из [10](10_action_list.md) §1).
2. Если есть — посмотреть цену и установки: занято ли плотно.
3. Прочитать комментарии под самим предложением в трекере: там пишут, каким
   приложением обходятся.
4. Проверить, не закрывает ли задачу бесплатное приложение вендора.

## 4. Рекомендация

**Строка 1, в рамке docs-as-code, а не «Markdown для LLM».**

| Критерий | Оценка |
|---|---|
| Спрос | 2 900 голосов, топ-8 всех запросов к Jira, 5–7 лет без решения |
| Цена | $175–450 за 200 мест — верхний квартиль рынка |
| Сегмент | корпоративный: docs-as-code нужен инженерной организации, не команде из десяти человек |
| Конкуренция | 4 заметных приложения, лидер 1 078 установок — не пусто, но и не плотно |
| Forge | синхронизация с внешним git **требует egress** → **теряется Runs on Atlassian и 100% ревшары** |

**Последняя строка — серьёзная,** и её надо решить до кода: по
[02](02_forge_implementation.md) §1.1 egress стоит бейджа и ревшары. При этом
«GitLab Integration for Jira Two-Way Sync» помечено как **FORGE** и берёт
$450 — значит вендор сознательно разменял бейдж на функцию и продаёт дороже
рынка. Это рабочая стратегия, но она отменяет один из доводов, на которых
Forge выбирался в [01](../ideas/01_third_sphere_market_analysis.md).

Альтернатива без egress: **односторонний экспорт** пространства Confluence в
Markdown-архив, который пользователь сам кладёт в git. Бейдж сохраняется,
цена ниже, конкурент — Markdown Exporter for Confluence (2 220 установок, $75).

**Что нужно от вас:** выбрать из двух рамок — двусторонняя синхронизация с
git за $175–450 ценой бейджа, либо экспорт без egress за ~$75 с бейджем.
