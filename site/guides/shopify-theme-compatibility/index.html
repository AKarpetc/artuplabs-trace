AR Room block — Shopify theme compatibility

We added the AR Room button block to a product page in nine Shopify themes and checked two things: does the block show, and does “View in my room” open the room. Here is what we found.

Dawn, Refresh, Sense, Craft, Studio and Horizon are free Shopify themes. Prestige, Impulse and Broadcast are paid themes; we tested them as theme trials.

What it looks like

How to add the block

  1. In Shopify admin open Online Store → Themes and click Customize.
  2. Switch to a product template (the page selector at the top).
  3. In the product information section click Add block, open Apps and choose AR Room button.
  4. Drag the block where you want it (for example under the buy buttons) and click Save.

The block shows “View in my room” and “Add to my room” only on products that have a 3D model. Labels and the button color are in the block settings.

Notes

  • Horizon: the block is placed under the product gallery by default, across the page. Drag it into the product information column in the theme editor if you want it next to the buy buttons.
  • Impulse: the block is added at the bottom of the product column, below the collapsible tabs. Move it up in the theme editor if you want it closer to Add to cart.
  • Broadcast: the block shows, but the theme cancels clicks on links whose address is a placeholder “#”, and our button used one until the page script filled in the room address. The fix renders the real room link in the page itself; we will re-test Broadcast after the app update and change this page.
  • Paid themes (Prestige, Impulse, Broadcast) were tested as theme trials, not on a live store using them.
  • Performance: the block adds 3 requests, about 5.3 KB transferred (a 386-byte stylesheet and two scripts of 2.2 KB and 2.7 KB); both scripts load with defer. We have not yet measured the effect on LCP or CLS.
  • Your theme not listed? The block uses Shopify's standard app block, so most Online Store 2.0 themes should show it. If it doesn't work in yours, write to support@artuplabs.com with the theme name and version.
